# Linux Basics

## What is Linux?

Linux is an open-source operating system widely used in servers, computers, cloud environments, networking, and cybersecurity.

## Basic Linux Commands

### pwd

Shows the current working directory.

```bash
pwd
```

### ls
Lists files and directories
```bash
ls
```

###cd
changes the current directory.

```bash
cd Documents
```
### mkdir
creates a new directory.

```bash
mkdir practise
```

### touch
creates a new empty file.

```bash
touch notes.txt
```
### cat
Displays the contents of a file.

```bash
cat notes.txt
```
